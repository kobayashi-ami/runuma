# 走るウマ改め「働くロボット」🤖

メニューバーをドット絵のロボットが占拠する常駐アプリ（旧・ウマ版 RunCat クローンから乗り換え）。

**二体編成**: 左が CPU ロボット（メニューバーの文字色の単色）、右が鏡写しの GPU ロボット（カラー: 緑のペットボトルの胴・銀のジャンクのフレームとジャバラ・赤い丸目。iCarly のスペンサー製ボトルロボットの写真から起こした）。GPU 側は frames.py の `gpu_robot()`、色の文字は S=銀 G=緑 R=赤。復帰時は緑の精子が泳ぎ出る。画像はテンプレートをやめて自前で塗り、メニューバーの明暗に合わせて色を切り替える。まんなかのエレベーターを二体で共有する。
GPU は IOKit の `IOAccelerator` → `PerformanceStatistics` → `Device Utilization %` を読む（sudo 不要）。ローカルAI（ollama 等）は GPU を燃やすので、右のロボットが踊る。
**ジャム**: 二体ともループ中（レベル1〜3）なら、遅いほうが速いほうの BPM に引っ張られて同じ拍で動き、GPU のドゥンドゥンは裏拍で沈む（交互の掛け合い）。どちらかが退勤するとソロに戻る。メニューに「♪ ジャム中 / ソロ / 二体とも退勤」。
**最高潮と粘り**: 80% を超えてもすぐには退勤しない。万歳して跳ねる「最高潮」で踊り続け、80% 超えが **60秒** 続いたら（`kHoldOutSecs`）エレベーターで退勤、80% を割ると復帰する。メニューに「最高潮・粘り 24/60秒」。
測定値は2秒ごとの瞬間値をならして使う（`kSmoothing`）。GPU の瞬間値は30〜90%台で暴れるため。
以下の段階は CPU・GPU で同じ境界を使う（表の「80%〜 職務放棄」は、いまは「80%〜 最高潮 → 60秒で職務放棄」）。

- **CPU負荷に応じて5段階のテンションで踊る**（静止→ゆらゆら→ノリノリ→本気ノリノリ→職務放棄）
- **CPUがほぼアイドル（8%未満）のときは微動だにしない** 🤖
- CPUが上がるとゆらゆら横揺れ→EDMのドゥンドゥンな縦ノリ→そのままBPMが上がっていく
- **CPUが80%を超えると「職務放棄」**：エレベーターの箱が降ってきて、扉が開き、ロボットがそのまま中へ入って扉が閉まり、箱が上へ去っていく。元いた場所は空白になり、メニューバーから完全に消える
- 負荷が下がると**エレベーター×精子**の演出で復帰：箱が降りてきて扉が開くと、中から精子が泳いで出てきて、ロボットの姿に変態して定位置に戻る
- アイコンをクリックすると **CPU使用率（現在のテンションつき） / メモリ / ストレージ空き / ネットワーク速度** を表示。開いている間も2秒ごとに更新
- メニューから **アクティビティモニタ** も開ける
- テンプレート画像なのでライト/ダークどちらのメニューバーにも自動で馴染む

## 使い方

```bash
./build.sh                # ビルド
open 走るウマ.app          # 起動
```

終了はメニューの「終了」(⌘Q)。

ログイン時に自動起動したい場合:
システム設定 → 一般 → ログイン項目 に 走るウマ.app を追加。

## しくみ

- 2秒ごとに `host_processor_info` でCPU使用率をサンプリング
- 使用率を5段階に区切ってレベル(0〜4)を決定:

| CPU | レベル | 動き | 再生間隔 |
|---|---|---|---|
| 〜8% | 0 | 静止（1フレーム、微動だにしない） | — |
| 〜30% | 1 | ゆらゆら横揺れ（4フレーム） | 0.35秒 |
| 〜55% | 2 | EDMドゥンドゥン（2フレーム） | 0.22秒 |
| 〜80% | 3 | ②と同じ動きでBPMアップ | 0.11秒 |
| 80%〜 | 4 | 職務放棄（下記シーケンス→空白で停止） | 0.09秒/コマ |
- ロボットは 28×18px の1ビット・シルエット。頭に目穴を2つ開けて表情をつけている
- レベル0〜3の間は普通にループ切り替え。**4に上がる瞬間だけ「職務放棄」シーケンス（箱降下→着地→扉オープン→入室→扉クローズ→箱上昇→空白）を1回再生**し、以後CPUが下がるまで完全な空白（アイコン非表示相当）で停止する
- **4から0〜3へ下がる瞬間だけ「復帰」シーケンス（箱降下→着地→扉オープン→精子が泳いで出てくる→ロボットへ変態→扉クローズ→箱上昇）を1回再生**してから、そのときのCPUレベルのループへ合流する
- どちらのシーケンス再生中もCPUサンプリングは続けるが、シーケンスの途中で新しいレベルに割り込むことはせず最後まで再生してから反映する
- メモリはアクティビティモニタの「使用済みメモリ」と同じ式で計算

## ファイル

| ファイル | 役割 |
|---|---|
| `main.m` | アプリ本体（ObjC 単一ファイル）。状態機械は `AnimMode`（Loop/PlayVanish/BlankHold/PlayReappear）で管理 |
| `frames.py` | ドット絵デザインツール。ロボット本体・エレベーターの箱・精子をコードで組み立てて生成する。`python3 frames.py sheet out.png [idle\|sway\|bounce\|blank\|vanish\|reappear]` でプレビューPNG生成、`python3 frames.py dump` で main.m 用のC配列を出力（フレームを変えたら貼り直す） |
| `build.sh` | ビルドスクリプト |
